# The District Website

The District's 2026 website and staff control centre.

## 2026 rebrand
- New **Signal Lime** identity (`#B5FF36`) based on the green lighting in the official District logo.
- Full graphite/black visual system across the public site, dashboard, applications, rules, creators and staff tools.
- Rebuilt homepage with launch control, release countdown, city systems, launch events and joining flow.
- Reworked navigation, favicon, motion, responsive layouts and internal control-centre styling.
- New Staff Panel **Change Logs** publisher with live Discord embed preview.

## Change log Discord setup
Read `REBRAND_SETUP.md` before deploying. The publisher requires either a Discord channel webhook or bot token stored as a Cloudflare Pages secret.
